# Glossary

## Who is this for

- Anyone reading Stellart docs who needs consistent terminology.

## Terms

- **Commission**: A custom work request from buyer to artist.
- **Advance payment**: First 50% payment required to start commission flow.
- **Remaining payment**: Final 50% payment paid before completion.
- **Preview upload**: Work-in-progress upload, typically watermarked.
- **Final upload**: Clean final artwork file delivered after completion.
- **Open commissions**: Artist setting that enables new commission requests.
- **Buyer**: User requesting and paying for custom or listed artworks.
- **Artist**: User creating custom and listed artworks.
- **Order**: Physical shipment record linked to a purchase.
- **Carrier**: Shipping provider used for order shipment.
- **Tracking code**: Shipment reference number set by seller.

## Commission statuses

- `pending`: Request created; waiting for artist action and/or payment readiness.
- `accepted`: Artist accepted request.
- `in_progress`: Artist started working.
- `review`: Buyer reviews submitted work.
- `revised`: Revision requested and pending updated submission.
- `completed`: Buyer approved and commission closed.
- `refunded`: Payment returned after denial/refund process.
- `cancelled`: Commission cancelled before completion.
